Send results to RunScore

RunScore takes results over a TCP connection on the computer it runs on. This site cannot reach into that computer, so a small program running there fetches each new result from here and hands it to RunScore. It runs in Windows PowerShell, which every Windows computer has: there is nothing to install.

  1. In RunScore, set up the timer input for RunScore's open format (lines that begin with RSBI) over TCP, start it, and note its port.
  2. Enter that port here. The line below changes with what you enter.
  3. On the scoring computer, open Windows PowerShell, paste the line and press Enter. Leave that window open for the race. It shows every result it passes on.

The line contains the access key, so treat it like a password. A result is passed on about eight seconds after it is recorded, which gives the camera time to correct a number. RunScore cannot be asked to take a result back: if one is corrected or deleted on an iPad after it was passed on, the PowerShell window says so, and it has to be put right in RunScore by hand.
